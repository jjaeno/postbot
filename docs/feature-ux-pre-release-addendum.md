# 출시 전 기능·UX 명세 보완

기준일: 2026-10-05. `Postbot_기능_UX_명세서_v0.2.docx`의 출시 전 구현 범위와 제한을 명확히 하는 보완 명세다. 기존 DOCX의 로드맵 전체를 완료한 것으로 해석하지 않는다.

## 화면 기반 제작·운영

* 홈에서 오늘 실제 예약·성공·실패, 다음 게시, 검수, 재고 부족, 계정 연결, 예산 설정으로 이동한다. 반복 슬롯 수는 실제 게시 예약 수와 구분한다.
* 채널 마법사는 제출 전 설정 요약, 단계별 입력 검증, IANA 시간대 검증, modal focus와 Escape 닫기를 제공한다. 입력 중 불완전한 값으로 schema 예외를 일으키지 않는다.
* 채널의 생성 언어·목표 시청자·말투·훅·CTA·길이와 게시 한도는 화면에서 수정한다. 변경은 이후 제작에 적용되며 기존 예약 snapshot을 덮어쓰지 않는다.
* 아이디어에서 플랫폼을 선택해 전체 제작을 시작한다. 요청 중 재클릭을 막고 동일 소재·플랫폼의 시작 요청은 멱등 키를 재사용한다.
* 제작 단계, 완료 단계 수, 경과 시간과 실패 원인을 조회하고 플랫폼·단계 단위 재시도 및 제작 취소를 제공한다. 진행 조회는 REST polling을 사용하므로 SSE 연결 없이도 새로고침 후 복구된다.
* 콘텐츠 검색·채널·상태·플랫폼 필터, 제목 클릭, URL의 콘텐츠 선택 상태를 제공한다. 내부 ID 직접 입력은 요구하지 않는다.
* 검수 화면은 플랫폼별 영상, 대본, 출처, 권리, 정책 검사, 제목·설명·해시태그를 보여준다. 자동 갱신이 저장 전 입력을 덮어쓰지 않는다.
* 부분 재생성은 훅·본문·메타데이터·장면 이미지·전체를 선택한다. 선택 플랫폼의 새 버전과 이미지·음성·영상·정책 검사를 다시 만들며 서버 비용 산정과 예산 검사를 통과해야 실행한다. 화면에서 상세 진행을 추적하고 완료된 새 버전을 자동 조회한다.
* 메타데이터 편집은 기존 scene와 권리 증거를 유지하지만 정책 재검사·재승인이 필요하다. 해당 플랫폼의 기존 예약은 보류한다.
* 검수 승인 후 보류된 게시 branch가 자동 재개된다. 한 플랫폼의 승인·보류·실패가 다른 플랫폼의 정상 결과를 대신 승인하거나 차단하지 않는다.
* 캘린더는 반복 규칙과 실제 PublishPlan을 분리하고 URL·예약/게시 시각·실패를 표시한다. 예약 변경은 기존 예약 취소 후 검수 화면에서 새 예약을 저장하는 명시적 두 단계다. 게시 시작 후에는 취소/변경하지 않는다.

## 비용·권리·시간

* 일간/월간 soft/hard 예산을 workspace 또는 channel 범위로 설정한다. 서버 단가와 작업량으로 예상 비용을 계산하고, 실 Provider 단가 미설정은 보류한다. estimated와 실제 청구 확정은 구분한다.
* Fake 이미지/음성만 테스트용 verified 권리를 갖는다. 실제 이미지·음성의 상업 사용 권리를 임의로 승인하지 않는다.
* 소유자는 검수의 권리 증빙 화면에서 라이선스 이름과 HTTPS 증빙, 상업 사용·변형 허용 여부를 검토한 후 승인/거절한다. 서버는 소유권과 권한을 확인하고 변경 이력을 audit에 남긴다. URL의 존재만으로 자동 검증하지 않는다. 변경 후 재검사·재승인이 필요하다.
* 수동 입력은 기기 현지 시간으로 표시하고 UTC ISO로 저장한다. 반복 일정은 규칙의 IANA 시간대로 해당 날짜의 UTC offset을 계산하며 DST gap의 존재하지 않는 시각은 건너뛴다.
* 수동·자동 예약은 채널 잠금 아래 플랫폼별 현지 날짜의 일일 한도와 계정의 실제 점유 시각을 검사한다. 자동 예약은 점유/한도 초과 후보를 건너뛰고 경쟁 충돌은 보류한다.

## 분석·연동과 제공 제한

* 분석의 채널·플랫폼·최근 7/30/90일을 선택한다. 불가 지표와 마지막 동기화 시간을 표시한다. 최적화 전략 적용 이력과 이전 전략으로 되돌리기를 제공하고 콘텐츠에 적용 context/전략 version을 저장한다.
* 실제 OAuth browser callback은 신뢰된 WEB_BASE_URL로 복귀하며 성공 시 채널을 표시한다. 실패·거절·만료는 재연결 안내를 제공하고 코드·토큰·제공자 오류 원문을 redirect URL에 넣지 않는다.
* 조회 실패는 별도 오류 안내이며 비용 0으로 대체하지 않는다. 성공 메시지는 오류와 구분한다.
* 영상 출력은 9:16, 1080×1920, 가독성 자막으로 고정 지원한다. 자유 출력 비율·자막 테마·자유 편집기는 제공하지 않는다.
* 실험은 수동 assignment 및 상태 관리까지만 제공한다. 제작 자동 배정·결과 비교는 미구현이며 `complete` 요청은 거부한다. 실험 완료나 인과 효과를 주장하지 않는다.
* 실제 유료 API, SNS 게시, 앱 심사, 운영 배포는 로컬 Fake 검증과 별도의 외부 검증 대상이다.
