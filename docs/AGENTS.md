# Postbot 문서 작업 규칙

루트 `AGENTS.md`를 따른다.

문서를 수정할 때 추가로 다음 규칙을 적용한다.

1. 현재 변경과 관련된 문서만 확인하고 수정한다.
2. 기능 명세, 기술 결정, 구현 계획 또는 실제 코드 사이의 충돌을 발견하면 명시적으로 기록한다.
3. API, 환경 변수, 상태 전이, 운영 방법 또는 아키텍처 결정이 변경되면 같은 단계에서 관련 문서를 갱신한다.
4. 플랫폼 정책, Provider, 가격, 모델명, 라이선스 등 변경 가능한 정보에는 확인일 또는 갱신 책임을 기록한다.
5. 수익화 승인 또는 수익 발생을 보장하는 표현을 사용하지 않는다.
6. 실제 API 키, OAuth 토큰, 개인정보 또는 기타 비밀값을 기록하지 않는다.
7. 실행하지 못한 검증은 이유와 필요한 환경을 기록한다.

`Postbot_Codex_전체_개발_프롬프트.md`는 전체 개발 로드맵 참고용이며 단계별 문서 수정의 기준으로 사용하지 않는다.
