# Postbot docs 작업 규칙

이 디렉터리의 문서는 루트 `AGENTS.md`의 규칙을 따른다. 특히 다음 파일은 Postbot v1 개발의 기준 문서다.

- `docs/Postbot_기능_UX_명세서_v0.2.docx`
- `docs/Postbot_v1_기술_스택_확정서.docx`
- `docs/implementation-plan.md`
- `docs/architecture-decisions.md`
- `docs/Postbot_Codex_전체_개발_프롬프트.md`

## 문서 작업 규칙

1. 문서 수정 전 루트 `AGENTS.md`, 이 파일, 관련 기준 문서를 읽어라.
2. 기능 명세, 기술 스택 확정서, 구현 계획, 아키텍처 결정 기록 사이에 충돌이 있으면 숨기지 말고 문서화하라.
3. 현재 단계 범위를 벗어난 앱 코드나 디렉터리 구조를 만들지 마라.
4. 단계 번호와 커밋 메시지는 `docs/Postbot_Codex_전체_개발_프롬프트.md`와 맞춘다.
5. API, 환경 변수, 상태 전이, 운영 방법이 바뀌면 같은 단계에서 관련 docs를 갱신하라.
6. 플랫폼 정책, 외부 Provider, 가격, 라이선스처럼 바뀔 수 있는 정보는 확인일과 갱신 책임을 기록하라.
7. 수익화 승인이나 수익 발생을 보장하는 표현을 쓰지 마라.
8. 실제 API 키, OAuth 토큰, 개인정보, 비밀값을 문서에 적지 마라.
9. 실행하지 못한 검증은 이유와 필요한 환경을 명시하라.
10. 완료 후 변경 파일, 핵심 내용, 검증 결과, 남은 위험을 요약하라.
